PyrusLLM

PyrusLLM is a peer-to-peer marketplace for AI inference. One binary turns a machine into an inference provider: it joins a live peer-to-peer network, announces an Ed25519-signed manifest describing the model it runs and the capacity it has, and serves requests through an OpenAI-compatible gateway on 127.0.0.1:8787. Any OpenAI client points at that gateway unchanged and is routed to a node by price and availability, with no company in the middle taking a margin or seeing every prompt. Peer-to-peer and local inference cost nothing today; payment over x402, in USDT0 stablecoin and on testnet only, is what starts to change that. The Airbnb of AI compute — or, for anyone who knows the space, a peer-to-peer OpenRouter.

Run it from source (recommended)

git clone https://github.com/gazzimon/qvac_node.git
cd qvac_node
npm install            # needs npm >= 10
npx bare bin.mjs       # app on http://localhost:8787, opens the browser
npx bare bin.mjs prompt "what is a p2p network?"   # 100% local, nothing opens

This runs the current tree. The OTA-distributed binary can lag behind the repo, and on Linux only the from-source path can load models.

Or install the binary

curl -fsSL https://raw.githubusercontent.com/gazzimon/qvac_node/main/install.sh | sh
irm https://raw.githubusercontent.com/gazzimon/qvac_node/main/install.ps1 | iex

Linux: the standalone binary installs but can't load models yet — use the from-source path above.

What a node could earn once inference is paid for

Nothing on the network charges today. This models the economics x402 is meant to open up: payback is capital divided by the tokens a machine actually produces, so the question is never "how fast is this hardware", it is "how many hours a day is it producing tokens somebody values". Every cell is the same machine and the same model — only how busy it is and what its tokens are worth change. That spread is the whole business.

How this is computed. Generating a token reads the whole model out of memory once, so throughput is bounded by memory bandwidth: tok/s ≈ bandwidth × 75% ÷ model size. These are physical-limit estimates, not measurements on the machines, and bandwidth figures come from each machine's memory spec. Prices are list, with no import duty added. Payback is capital ÷ monthly net; NPV discounts 36 months at 12% a year.
