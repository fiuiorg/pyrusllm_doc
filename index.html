Owned by no one. Run by everyone.

Turn your machine into a node on a peer‑to‑peer inference marketplace.

PyrusLLM installs over P2P, updates itself over OTA, and exposes an OpenAI‑compatible endpoint to a swarm of other nodes. Each node announces a signed manifest — what it serves, what it charges, how loaded it is — and every answer that comes back carries provenance: which machine produced it, how fast, and what it cost.
