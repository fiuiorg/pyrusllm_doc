Browser panels

pyrusllm serve also serves four pages. They are plain clients of the API documented in this site — same Bearer key, no privileged path.

RoutePanel
/Chat — ask the network; every answer names the machine that produced it
/nodeMy Node — your machine as a provider: status, load, rate, keys, traffic, meters
/networkNetwork — every node this machine knows about, and their files
/walletWallet — address, balance, movements, send, network and token settings
/adminAdmin — all nodes plus the raw routing log
The API Playground on this site is a fifth client of the same routes — it just talks to whichever node's Base URL you give it, instead of always localhost.
