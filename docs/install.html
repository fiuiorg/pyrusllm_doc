Install & quickstart

Two ways to get the binary, then three commands to a working completion.

Install

Over npm

npm install -g pyrusllm

Over P2P (Pear)

pear install pear://8f789f6hsf4ghymku5eqwqmbqiubiigp8xpy6boiymunnbyznpny
The npm package ships a Node launcher that delegates to the Bare runtime; the node itself does not run on Node. The correct Bare binary for your platform is pulled in as an optional dependency at install time.

Quickstart

1. Answer a prompt, fully offline

pyrusllm prompt "Explain peer-to-peer in one sentence"

2. Start the gateway and join the network

pyrusllm serve --swarm --operator "your name"

3. Call it like OpenAI

curl http://localhost:8787/v1/chat/completions \
  -H "Authorization: Bearer $PYRUS_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"llama1b","messages":[{"role":"user","content":"hello"}],"stream":true}'
You need a key for step 3. Create one from the My Node panel, with POST /v1/keys, or from the API Playground.
