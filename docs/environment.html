VariableDescription

PYRUS_WALLET_REDPins the network. When set, the panel's network selector is disabled
PYRUS_WALLET_RPCOverride the RPC endpoint

PYRUS_X402_PLASMA_ASSET_VERIFICADOMust be 1 to charge on Plasma mainnet — a human step: verify the USD₮0 contract on the explorer first

All of these can live in a .env in the storage directory.

Models

Aliases accepted by --model and by the model field:

smol llama1b (default) qwen1_7b qwen4b qwen8b gemma4b

An exact registry name also works. The catalog exposed by /v1/swarm/manifest marks each model with fits, computed against this machine's RAM.
