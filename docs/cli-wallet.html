CLI — wallet

Show, create or restore this node's payout wallet from the terminal.

pyrusllm wallet

pyrusllm wallet [--create | --restore "<24 words>"]
FlagDescription
(none)Show the payout address, or say there is no wallet yet
--createGenerate a new wallet for this node
--restore <phrase>Restore from the 24 words of a backup
The 24 words are shown once. Write them down. Without them and without the keystore, the wallet is lost. The seed is stored encrypted with PYRUS_WALLET_PASSPHRASE; if that .env lives next to the keystore, the encryption protects against a backup or a repo — not against somebody who already has access to the machine.
Never keep a recovery phrase in a plain text file next to files you share. A 24-word seed in a .txt on the desktop, inside a folder you hand to someone else or sync anywhere, is a live risk — treat it the same as the wallet itself.

See also the wallet API routes — the CLI command and /v1/wallet/* operate on the same keystore, and only the node process ever opens the seed.
