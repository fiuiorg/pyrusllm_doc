Documentation / API reference

Network

Who is on the swarm, whether this node has joined it, and what it routed.

List nodes

GET/v1/nodesBearerTry it →

The rich marketplace view: operator, price, load, kind. Returns { nodes, swarm }; swarm is null when this gateway has not joined the P2P network yet.

Node kindMeaning
realThis machine
peerA genuinely remote node, discovered over the swarm, signed manifest verified
mockSimulated (--demo). Always labelled as such in the UI
upstreamReached over HTTP. May be a third-party API or a local engine — check local
knownIn the directory, manifest verified once, but no socket now. Never a routing candidate

Agent status

GET/v1/agentNo keyTry it →

Whether this machine has joined the network. Statuses: offline, launching, live, error. Also carries canLaunch — false when the gateway was started without swarm support.

Launch the agent

POST/v1/agent/launchBearer

Joins the P2P network at runtime — the API equivalent of restarting with --swarm. Requires a gateway started with launch support.

Not offered live in the playground — it changes what your node is doing on the network. See what the playground restricts for the curl version.

Swarm manifest

GET/v1/swarm/manifestBearerTry it →
POST/v1/swarm/manifestBearer

GET returns the signed manifest, the model catalog with a fits flag per model (does it fit in this machine's RAM), and modelLoad status. POST edits displayName, tags, maxConcurrentRequests or modelId and re-signs.

Switching modelId triggers a real model load. It can take several seconds or fail for lack of memory, while the node keeps answering with the current model. On failure the current model is kept.

Routing log

GET/v1/routing-logBearerTry it →

Both directions of the exchange, separated by kind: served is what this node produced for a peer, route is what it asked of somebody else. Each entry carries tokens, TTFT, tok/s, the D25 prefill/decode split with its tokensFuente provenance, and finishReason.
